# AI Film & Drama Studio Master v2.0
ชุดระบบออกแบบและควบคุมการผลิตหนังสั้น ภาพยนตร์ และซีรีส์ด้วยคำสั่ง Prompt เป็นหลัก

## ความสามารถ
- Prompt-only orchestration: ผู้ใช้ระบุโจทย์หลักครั้งเดียว ระบบแตกงานและจัดลำดับขั้นตอนให้อัตโนมัติ
- Vertical drama: วิดีโอแนวตั้ง 9:16 พร้อมโครงสร้าง hook, escalation และ cliffhanger
- Regional drama: โหมดไทย เกาหลี และจีน พร้อมแนวทางตรวจสอบบริบทวัฒนธรรม
- Creative randomizer: สุ่มแนวคิด/องค์ประกอบใหม่ในแต่ละโปรเจกต์ โดยไม่สุ่มทับข้อกำหนดของผู้ใช้
- Top-10 audience research: เก็บข้อมูล 10 อันดับที่ตรวจสอบแหล่งที่มาได้ ก่อนสังเคราะห์ความนิยม
- Automated quality gates: คะแนนขั้นต่ำ 90/100 และไม่ผ่านหากมีข้อผิดพลาดวิกฤต
- Provider adapters: แม่แบบเชื่อมต่อผู้ให้บริการภาพ วิดีโอ เสียง เพลง ตัดต่อ และค้นคว้า

## สถานะและข้อจำกัด
นี่คือแพ็กเกจสเปก/เอกสารพร้อมแม่แบบการทำงาน ไม่ใช่ซอฟต์แวร์ที่เชื่อมต่อบริการภายนอกให้แล้วโดยอัตโนมัติ
การสร้างภาพ/วิดีโอ/เสียงจริงต้องเชื่อมต่อ API หรือเครื่องมือที่รองรับ และกำหนดสิทธิ์/ค่าใช้จ่ายก่อนใช้งาน
คำว่า “ทุกแพลตฟอร์ม” ใช้ผ่าน adapter interface; ความสามารถจริงขึ้นกับ API, เงื่อนไขบริการ และรูปแบบไฟล์ของแต่ละแพลตฟอร์ม

## เริ่มใช้งาน
1. อ่าน `00_CORE_SYSTEM/MASTER_SYSTEM.md`
2. ปรับ `00_CORE_SYSTEM/PROJECT_DEFAULTS.yaml` ตามทีม/งบประมาณ/แพลตฟอร์ม
3. ใช้ `04_WORKFLOWS/PROMPT_TO_FILM/WORKFLOW.md` เป็น workflow หลัก
4. เชื่อมต่อผู้ให้บริการตามแม่แบบใน `03_PLUGINS/`
5. ทดสอบด้วย `05_EVALUATION/TEST_PLAN.md` ก่อนใช้งานจริง

> สร้างซีรีส์แนวตั้ง 9:16 จำนวน 12 ตอน ตอนละ 90 วินาที แนวโรแมนติก-ลึกลับ ฉากประเทศไทย ภาษาไทย โทนภาพสมจริง กลุ่มเป้าหมายวัย 18–34 ปี งบประมาณระดับกลาง
