# Character Bible
บันทึกชื่อ/ชื่อเรียก อายุที่เรื่องกำหนด รูปลักษณ์ที่จำเป็น บุคลิก เป้าหมาย ความกลัว ความเชื่อผิด ความขัดแย้งภายใน ความสัมพันธ์ วิธีพูด wardrobe/props และ arc
กำหนด invariant visual keys เช่น ทรงผม แผลเป็น เครื่องประดับ และสีเครื่องแต่งกาย พร้อมรายการเปลี่ยนแปลงที่อนุญาตตามเวลาเรื่อง
หลีกเลี่ยงการสร้างตัวละครจาก stereotype ของชาติ เพศ อาชีพ หรือชนชั้น
