# Directing
ทุกช็อตควรมีหน้าที่ทางอารมณ์/ข้อมูล กำหนด blocking, eyeline, screen direction, performance intensity และ visual motif
การเคลื่อนกล้องต้องมีเหตุผล; รักษา axis/180-degree rule เว้นแต่ตั้งใจเปลี่ยนเพื่อผลทางเรื่อง
บันทึก directing intention แยกจาก prompt สำหรับเครื่องมือ เพื่อให้เปลี่ยน provider ได้
