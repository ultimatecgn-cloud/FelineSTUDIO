# Prompt to Vertical Drama Workflow
1. Confirm 9:16; define platform-safe zones and delivery specs.
2. Design series engine, episode count, duration, character arcs and season mystery.
3. Build hook/payoff map for every episode; ensure each cliffhanger follows causal story logic.
4. Write episode scripts with mobile-readable dialogue/subtitles and visual-first storytelling.
5. Lock character/wardrobe/location references; generate vertical boards and shots.
6. Produce clips, dialogue, score and SFX; check face/hand/prop consistency.
7. Edit for mobile pacing; test crop, subtitle readability, audio and first-frame appeal.
8. Score every episode and series continuity; no release below 90/100 or with critical failures.
