# Prompt to Film Workflow
1. Parse prompt → hard constraints/preferences/unspecified fields.
2. Create project ID, random seed, project brief and decision log.
3. Research relevant market Top 10; store source evidence and gaps.
4. Develop 3 concept candidates internally; select best-fit candidate using originality, feasibility and brief fit.
5. Create story bible, character bible, world bible and visual bible.
6. Draft logline, synopsis, beat sheet, screenplay and dialogue pass.
7. Breakdown script into scenes, assets, schedule and budget estimate.
8. Create storyboard, shot list, image/video prompts and sound plan.
9. Generate assets/clips through configured providers; validate each result.
10. Edit assembly, sound mix, color, subtitles and final master.
11. Run all QA gates; revise up to 3 rounds per gate.
12. Deliver only verified files plus manifest, credits, rights report and QC report.
